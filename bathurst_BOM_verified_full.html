✅ How verification works — BOM scrape method:
  1. BOM Official Source: Bureau of Meteorology station 063005 BATHURST AGRICULTURAL STATION — Commenced 1908 — 33.43°S 149.56°E 713m — Open【2277743868876562756†L22-L26】. Also 063004 BATHURST GAOL and 063291 AIRPORT AWS.
  2. Transcription Mirror: australianweathernews.com/data/archive/63/YYYY_MM.HTM is a verbatim transcription of BOM Climate Data Online daily observations. Example: 63/1963_10.HTM shows BATHURST AGRICULTURAL STATION (063005) 713.0m asl【5869106710491120223†L568-L572】 with rain sequence 5.1,0.3,0.0,0.0,0.0,0.0 for days 1-6【5869106710491120223†L574-L587】.
  3. Extraction: For each race date, extract day column N (1=1st, 6=6th, 19=19th etc). Example 1974 Oct 6: Rain row 0.8|0.9|0.0|10.4|5.2|13.6 — 13.6 on day 6【3499023599335756544†L36-L42】. Temperature section header Maximum & minimum air temperatures then Min 8.4 / Max 14.3 on same day.
  4. Phillip Island: Rhyll AWS 086373 elevation 13m started 1990【1896140356535574596†L205-L209】 — so 1960-62 use proxy 086361 Cerberus & 086354 Penguin Reserve. Same scrape method on district 86.
  5. 2026: Future scheduled — no BOM observation yet — shows climatological average only: Oct avg Max ~19-20°C Min ~7°C, 61.83mm month, 6 rainy days【6064066889460323482†L25-L28】, typical day 20°C/6°C【6064066889460323482†L53-L57】.

def fetch_archive(district, yyyy, mm):
    url = f"http://www.australianweathernews.com/data/archive/{district:02d}/{yyyy}_{mm:02d}.HTM"
    try:
        r = requests.get(url, timeout=20)
        if r.status_code==200:
            return r.text
    except Exception as e:
        print(f"fail {url} {e}")
    return None
